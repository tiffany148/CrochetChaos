A beginner's dictionary of every stitch name and abbreviation used in this book. Patterns are written in **US terms**; the UK name is given beside each one. Keep a finger in this page while you learn. The full reference chapter, Chapter 81 (Abbreviations, Symbols and US/UK Terms, in Part XV), adds the chart symbols.

> [!HINT] US or UK pattern?
> If a pattern uses "sc" (single crochet), it is written in US terms. UK patterns never use single crochet. The same word can mean a different stitch: a US double crochet (dc) is a UK treble (tr).

## Basic stitches and words

| US name | US abbr. | UK name | UK abbr. | What it means |
|---|---|---|---|---|
| chain | **ch** | chain | ch | Wrap the yarn over the hook and pull it through the loop on the hook. Chains start most projects. |
| slip stitch | **sl st** | slip stitch | ss | The shortest stitch: go into a stitch, wrap the yarn, and pull it through the stitch and the loop on the hook in one move. Used to join and to move along an edge. |
| single crochet | **sc** | double crochet | dc | A short, firm stitch: pull up a loop (2 loops on the hook), then pull through both. |
| half double crochet | **hdc** | half treble | htr | Yarn over first, pull up a loop (3 loops on the hook), then pull through all three. |
| double crochet | **dc** | treble | tr | Yarn over first, pull up a loop (3 loops), then pull through two loops at a time, twice. |
| treble (triple) crochet | **tr** | double treble | dtr | Yarn over twice, pull up a loop (4 loops), then pull through two loops at a time, three times. |
| double treble crochet | **dtr** | triple treble | ttr / trtr | Yarn over three times, then work off the loops two at a time. |
| triple treble crochet | **trtr** | quadruple treble | qtr | Yarn over four times, then work off the loops two at a time. |
| yarn over | **yo** | yarn over hook / yarn round hook | yoh / yrh | Wrap the yarn over the hook from back to front. |
| skip | **sk** | miss | — | Leave a stitch empty and go on to the next one. |
| stitch / stitches | **st / sts** | same | st / sts | One finished stitch, or several. |
| space / spaces | **sp / sps** | same | sp / sps | A gap made by chains or skipped stitches; you work into the gap, not into a stitch. |
| chain space | **ch-sp (e.g. ch-1 sp)** | same | ch-sp | The gap under a chain made in an earlier row or round. |
| loop / loops | **lp / lps** | same | lp | A loop of yarn, usually a loop on the hook. |
| round / rounds | **rnd / rnds** | same | rnd | One trip around a piece worked in a circle or tube. |
| row | **Row** | same | Row | One trip across a flat piece. |
| turning chain | **tch** | same | tch | Chains at the start of a row that lift the yarn to the new stitch height. |
| fasten off | **FO** | same | FO | Cut the yarn and pull the end through the last loop so the work cannot unravel. |

## Working words and special stitches

| US name | US abbr. | UK name | UK abbr. | What it means |
|---|---|---|---|---|
| back loop only | **BLO (also BL)** | same | BLO / tbl | Work into only the back strand at the top of the stitch. |
| front loop only | **FLO (also FL)** | same | FLO | Work into only the front strand at the top of the stitch. |
| through back loop | **tbl** | same | tbl | Same as back loop only. |
| front post | **FP** | same | FP | Go around the stitch post from the front instead of into the top. |
| back post | **BP** | same | BP | Go around the stitch post from the back instead of into the top. |
| together | **tog** | same | tog | Several stitches finished as one, usually to decrease (see the -tog list below). |
| increase | **inc** | same | inc | Make 2 stitches in the same stitch, so the count goes up by 1. |
| decrease | **dec** | same | dec | Join stitches so the count goes down. |
| invisible decrease | **inv dec** | same | inv dec | A single crochet decrease worked through front loops only, so it hardly shows. |
| cluster | **cl** | same | cl | Several partly made stitches finished together at the top. |
| popcorn | **pc** | same | pc | Several stitches in one place, folded together so they pop out. |
| foundation single crochet | **fsc** | foundation double crochet | fdc | A chain and a first row of single crochet made at the same time. |
| foundation half double crochet | **fhdc** | foundation half treble | fhtr | A chain and a first row of half double crochet made at the same time. |
| foundation double crochet | **fdc** | foundation treble | ftr | A chain and a first row of double crochet made at the same time. |
| extended stitch | **ext (esc, edc)** | same idea | — | A stitch with one extra chain-like step at the bottom, so it is a little taller (esc = extended sc, edc = extended dc). |
| Tunisian simple stitch | **tss (Tss)** | same | tss | The basic Tunisian stitch: pick up a loop under each front vertical bar. |
| Tunisian knit stitch | **tks (Tks)** | same | tks | Tunisian stitch worked between the front and back vertical bars. It looks knit-like but is crochet. |
| Tunisian purl stitch | **tps (Tps)** | same | tps | Tunisian stitch with the yarn brought to the front before picking up the loop. |
| right side | **RS** | same | RS | The side that will show on the outside. |
| wrong side | **WS** | same | WS | The side that will be hidden. |
| place marker | **pm** | same | pm | Put a stitch marker in the stitch or loop. |
| slip marker | **sm** | same | sm | Move the marker up into the new stitch. |
| marker / meter | **m** | same | m | In instructions, m means marker; in measurements, m means meters. |
| main color | **MC** | same | MC | The color used most. |
| contrasting color | **CC** | same | CC | A second color. |
| repeat | **rep** | same | rep | Do the stated steps again. |
| remaining | **rem** | same | rem | What is left. |
| beginning | **beg** | same | beg | The start of the row or round. |
| between | **bet** | same | bet | Between. |
| continue | **cont** | same | cont | Keep going as set. |
| alternate | **alt** | same | alt | Every other one. |
| approximately | **approx** | same | approx | About. |
| previous | **prev** | same | prev | The one before. |

## Pattern punctuation

| Mark | What it means |
|---|---|
| \* | Repeat from the star as many times as the pattern says. |
| [ ] or ( ) | Work everything inside the brackets as a group, in one stitch or space, or the number of times stated. |
| (12) or = 12 | The stitch count you should have at the end of the row or round. |
| 2 sc in next st | Two stitches in the same stitch: an increase. |
