Diagnose the fabric before changing it. A piece can have the correct count and the wrong insertion path, or the wrong count and an apparently straight edge. Use counts, stitch anatomy, dimensions, and the written instructions together. None of those checks alone explains every problem.

## Secure the live loop and record the symptom

Put a locking marker through the live loop before setting the work down. Lay the piece flat without stretching it. Photograph the region and mark the last row or round whose count you know. Write the expected and actual counts separately.

Describe what you see: one extra top V at an edge; a gap under a color change; a ridge that switches faces; a circumference that grows despite even rounds. A concrete symptom suggests a specific inspection. “It looks wrong” is the beginning of a diagnosis, not its conclusion.

## Count the input and output

Count the preceding row first. If it already has the wrong total, the current row may simply preserve that earlier error. Then divide the current instruction into edge actions and repeats. Calculate how many old destinations each consumes and how many new units it produces.

Suppose a row should consume 24 stitches using eight repeats that each consume three. If you have only 23 input stitches, the eighth repeat cannot fit as written. Adding an arbitrary final stitch may conceal the count difference while leaving the actual shaping misplaced.

Use removable markers to isolate repeats. If a 60-stitch row contains six ten-stitch groups, identify the first group where the count diverges. That narrows the search from an entire row to ten stitches.

## Inspect the edges

At a widening edge, check whether both the first actual stitch and a counted beginning chain were worked. At a narrowing edge, check whether the final stitch or counted chain top was missed. Verify the pattern’s convention instead of imposing the convention from a previous project.

A row-end chain can look like another top V. A slip-stitch join can look like another round stitch. Mark the first and last actual stitches to distinguish structural boundaries from attractive extra insertion opportunities.

## Trace the yarn path

Choose a nearby correct stitch as a comparison. Identify its top loops, post, base, and neighboring opening. Compare the questionable stitch. Did the hook pass under both loops, one loop, a third loop, a post, or the space between stitches?

A split stitch catches only some yarn plies. It may preserve the row count but distort the surface and snag during later work. An unfinished double crochet may retain an extra loop and accidentally become part of a shared closure. A slip stitch made instead of single crochet shortens a local area without necessarily changing the count.

## Diagnose shape with correct counts

| Symptom | Count-preserving cause to investigate | Additional check |
|---|---|---|
| Circle cups | Expansion rate unsuitable for stitch proportions | Compare actual row height and circumference |
| Circle ruffles | Excess expansion or too much chain length | Inspect placement and tension as well as totals |
| Rib becomes smooth | Wrong loop selected | Trace unused strands |
| Texture swaps faces | Incorrect post direction after turn | Check RS marker |
| Panel narrows at colorwork | Carried strand too tight | Spread fabric gently and inspect reverse |
| Border pulls inward | Inadequate edge distribution or tight stitches | Compare edge length before and after border |
| Seam gathers | Seaming yarn too tight | Ease a small section and remeasure |

This table suggests inspections, not one guaranteed cause per symptom. A ruffled circle can also contain accidental increases; count before blaming geometry.

## Gauge drift

Measure a central section at several levels. A gradually changing width with stable counts can indicate tension drift, a different hook, a changed yarn feed, or increased fabric weight. A sudden change can correspond to a new ball, a new technique, or an unrecorded tool swap.

Check whether the piece is fully dry and relaxed. A damp or stretched measurement can imitate a gauge change. Compare the actual fabric with the treated swatch, not with a remembered number from before washing.

## Color and chart errors

Distinguish the wrong color from the wrong stitch structure. A miscolored single crochet can preserve the count, while a misplaced mosaic operation can change attachments. Confirm chart direction, row number, repeat phase, and the meaning of each cell.

If a word is mirrored, the stitches may be internally correct but read from the wrong visual orientation. If a motif is shifted one cell, check whether an edge stitch was included in the chart or added outside it. Record the exact chart convention before reworking.

## Decide whether to correct

Correct errors that affect fit, strength, intended structure, or a pattern you intend others to reproduce. A minor purely decorative difference in a personal object can be accepted intentionally if it causes no functional issue. Document it so later instructions do not present the irregularity as the planned repeat.

Do not turn an unknown structural problem into a decoration by covering it. First determine whether the yarn and neighboring stitches remain sound. A flower sewn over a weak hole hides the hole; it does not automatically stabilize it.

## Diagnostic practice sample

Make a 15-stitch single crochet rectangle for six rows with a non-counting ch-1. On a separate practice version, deliberately work two sc in the first stitch of Row 4 and one in every remaining stitch. That row now has 16. Preserve 16 through Row 6.

Compare the two samples. Locate the first row where the width and count changed. Trace the two new stitch tops to their shared base. Then undo the altered sample to just before that increase and remake Rows 4–6 with 15. Status: original count-based diagnostic exercise, physically untested for this edition.

>
> Find the first wrong row, not merely the last row where the problem became obvious. Errors are often quieter when they begin.

> When the count is right, inspect placement. Counting harder will not reveal which loop the hook entered.
>
> Keep a few labeled mistake samples. A recognizable error is easier to fix the next time it introduces itself.

## Mistake finder

| You see | Probable mistake | Where to look |
|---|---|---|
| Edge slants outward | Extra stitch at the row ends | First and last stitches |
| Edge slants inward | Missed end stitches | Last stitch of each row |
| Hole in the middle | Skipped stitch or extra chain | The row with the hole |
| Ridge on the right side | Worked one row in a single loop | That row's stitch tops |
| Color blip in tapestry | Changed color one stitch late | The stitch before the blip |
| Ruffled circle | Too many increases | Compare counts to the schedule |
| Cupped circle | Too few increases | Compare counts to the schedule |

> [!DANG] Dang, I Wish I'd Known That! — Stop at the first wrong count
> The moment a count is wrong, stop. One row of undoing is easy; ten rows of "it will block out" rarely is.
