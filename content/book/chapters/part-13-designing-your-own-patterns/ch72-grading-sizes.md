Grading creates a set of related sizes while preserving an intentional design. It is not the same as multiplying every number by one percentage. Body proportions, garment ease, repeat multiples, shoulder relationships, and construction all influence the count set.

Start from documented body assumptions and finished measurements for the intended range. Do not silently invent a standard population or assign conventional size labels to a few convenient stitch counts. A custom size set can be useful when its assumptions are clearly stated.

## Define the measurement system

For each size, record the body measurements being accommodated, ease by location, finished dimensions, and the fabric gauge. Distinguish a flat panel width from circumference. State whether bands overlap and whether dimensions include seams.

A finished chest range does not automatically define upper arms, necklines, armhole depths, or lengths. Grade those intentionally. Real bodies do not enlarge uniformly in every direction, and a style may deliberately keep some dimensions constant between neighboring sizes.

## A four-size numerical framework

The following A–D set is a hypothetical grading exercise related to the panel construction in Chapter 40. It is not a standard body-size chart or a tested four-size pattern. All dimensions are nominal before measured seam effects, at 4 stitches and 5 rows per inch.

![sizing_grade (schematic illustration)](../../assets/figures/sizing_grade.png)

| Quantity | A | B | C | D |
|---|---|---|---|---|
| Body circumference | 36 in | 40 in | 44 in | 48 in |
| Stitches per equal body panel | 72 | 80 | 88 | 96 |
| Body rows | 110 | 115 | 120 | 125 |
| Nominal body length | 22 in | 23 in | 24 in | 25 in |
| Each shoulder region | 22 sts | 26 sts | 28 sts | 32 sts |
| Center neckline region | 28 sts | 28 sts | 32 sts | 32 sts |

For every size, twice the shoulder count plus the center neck count equals the panel count. Size C matches the 88-stitch panel framework in Chapter 40. That consistency is an arithmetic link, not proof that the other sizes fit anyone.

## Grade the sleeve relationship

| Quantity | A | B | C | D |
|---|---|---|---|---|
| Armhole depth each panel side | 35 rows | 40 rows | 40 rows | 45 rows |
| Full joining path in row ends | 70 | 80 | 80 | 90 |
| Sleeve-top stitches | 56 | 64 | 64 | 72 |
| Nominal upper sleeve circumference | 14 in | 16 in | 16 in | 18 in |
| Cuff stitches | 36 | 40 | 40 | 44 |
| Two-stitch increase events | 10 | 12 | 12 | 14 |
| Sleeve rows | 70 | 72 | 72 | 84 |

The stitch-to-row-end mapping is 0.8 throughout: 56/70, 64/80, and 72/90. At the hypothetical gauges, that maps equal nominal lengths. A physical seam sample must still establish compatibility and take-up.

Sizes B and C intentionally share the sleeve counts in this exercise. That shows a nonuniform grading choice; it does not claim those counts satisfy every wearer in the two chest ranges. Actual target upper-arm measurements may require a different table.

## Convert counts to event schedules

Size A grows from 36 to 56 stitches, requiring ten events that add two stitches each. One count-only schedule places them on Rows 7, 14, and every seventh row through Row 70. Sizes B and C use 12 events on every sixth row through Row 72. Size D uses 14 events on every sixth row through Row 84.

These schedules describe one possible distribution. If a cuff or straight upper section occupies part of the sleeve, remove those rows from the shaping span and redistribute events. State leading and trailing plain rows explicitly. The number of events is not the number of gaps between them.

## Repeat constraints across sizes

A lace multiple may prevent equal stitch increments. If a body repeat uses six stitches, a nominal 16-stitch increase between sizes does not equal a whole number of repeats. Options include uneven but documented increments, plain side panels, different repeat placement, or another stitch pattern.

Calculate the resulting finished dimensions after choosing compatible counts. Do not leave the measurement table at its original target values when rounding has changed the actual prediction. A chart and instruction set must agree with the same count decisions.

## Check extreme and intermediate sizes

Audit the smallest and largest sizes for construction behavior, then check every intermediate count rather than assuming interpolation worked. A neckline that remains constant can become disproportionately narrow or wide relative to shoulders. A yoke increase schedule can reach the chest count before the needed depth or vice versa.

For each size, trace the entire path from starting count to final sections. At a raglan division, calculate front, back, sleeves, corner allocations, and underarm bridges independently. For panels, check shoulder totals and actual sleeve-to-armhole lengths.

## Write multi-size instructions clearly

State the size order once and use it consistently. For four values, identify them as A (B, C, D), or use a table with named columns. Avoid mixing that notation with parentheses that mean stitches in one location without adequate context.

Include zero where a size intentionally omits an action and define any dash used as not applicable. When an instruction only affects some sizes, name them. A reader should not have to infer that an unexplained missing value means do nothing.

## Grading exercise

Verify every panel identity in the first table. Then calculate sleeve changes: 56−36 = 20, 64−40 = 24, 64−40 = 24, and 72−44 = 28. Divide by two to confirm 10, 12, 12, and 14 shaping events. Calculate each sleeve’s nominal length from its row count.

Finally, choose a hypothetical wearer whose upper arm needs 17 inches while their chest target corresponds to C. At 4 stitches per inch the sleeve target becomes 68 stitches. Keeping a 40-stitch cuff requires 14 increase events. That change also alters the joining relationship; adjust the armhole or construction and sample the result. Mixing dimensions is a redesign to calculate, not permission to copy isolated numbers without checking their connections.

>
> Calculate backward from every graded count to its finished dimension. That catches convenient counts that no longer match the promised size.
>
> Shared counts between neighboring sizes can be intentional. Shared fit claims still need evidence.
>
> Use one size-order key everywhere, including charts, schematics, materials, and captions. A correct number in the wrong position is functionally incorrect.

## Grading checks

- Use a recognized size chart, such as the Craft Yarn Council's standard body measurements, as the starting point, and state which chart you used.
- Grade every measurement in the same proportion only when the body changes that way; necklines and armholes do not grow at the same rate as chests.
- Check that every size's counts fit the stitch multiple, and adjust with edge stitches if needed.
- Check the smallest and largest sizes first; problems usually show up at the extremes.

> [!DANG] Dang, I Wish I'd Known That! — Put sizes in a spreadsheet
> A spreadsheet with one column per size and one row per measurement makes grading errors visible immediately.

> [!DANG] Dang, I Wish I'd Known That! — Test at least two sizes
> If you can only test one size, choose a middle size and an extreme. Untested sizes should be marked as untested.

> [!GRANNY] Granny's Wisdom
> A good pattern fits more than one body. A great one tells you which bodies it was tested on.
